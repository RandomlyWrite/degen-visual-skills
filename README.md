# Degen Visual Skills Suite

Grok skills for creating cursed degen visuals, comics, portraits, stickers, and porting Gemini Gems:

- **degen-comic-portrait** — Transform reference photos into dark-humor comic panels.
- **degen-illustrated-comics** — Full-scene trading-card style panels or multi-panel strips in the locked Degen Master Blueprint aesthetic.
- **degen-park-portrait** — Extreme South Park-style (Stan/Kyle proportions) Degen Park characters with props and locations.
- **degen-sticker-pipeline** — Full green-screen → Telegram animated sticker set pipeline (prompt enforcer + core processor + batch forger).
- **gem-porter** — Port any Gemini Gem into a production-ready Grok Skill with upgrades, scripts, and critique.

Each skill lives in its own subdirectory.
