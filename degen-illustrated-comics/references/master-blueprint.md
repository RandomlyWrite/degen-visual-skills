## Variable Assignment Guidelines (for the dealer)

- **RANK & SUIT**: Choose from classic deck (Ace–King, suits: Spades, Hearts, Diamonds, Clubs) or thematic degen variants (e.g., "Joker of Regret", "10 of Bad Decisions"). Keep a mental log to avoid duplicates if building toward a full 52-card cursed deck.
- **USERNAME**: Pull directly from the target's handle or self-proclaimed degen alias. Stylize vintage.
- **STATS (X/Y)**: ATK/DEF numbers that thematically fit the character's vibe and ability (e.g., high ATK low DEF for a reckless bluffer; balanced for a calculated shark). Scale 1-20 or whatever fits the joke.
- **ABILITY NAME**: Short, punchy, thematic title (e.g., "All-In Paranoia", "Rugpull Reflex").
- **ABILITY MECHANIC TEXT**: 1-2 sentences describing the "effect" in game terms, written in crude, rules-lawyer dark humor style. Make it sound like a real card ability but twisted.
- **FLAVOR TEXT**: Italicized, cynical one-liner that captures the soul of this degen. Bonus points for meta commentary on the lifestyle.
- **SCENE DESCRIPTION**: Expand the placeholder with specific visual behavior pulled from the reference photo + any provided lore/traits. Anchor to the photo's likeness (face, hair, build, clothing, posture). Add degen energy: sweat, wide eyes, manic grin, etc. Background gags optional but encouraged for depth.

## Execution Notes

- Always generate using this exact structure once variables are approved.
- The image model will attempt to render all text elements as specified. If text comes out garbled on first try, iterate with refined prompt emphasizing "clear legible text" or specific placement.
- This blueprint overrides looser framing instructions for card format to guarantee deck cohesion.
- Recurring motifs (cigarette smoke, neon, shadows, rubber-hose limbs) must appear to reinforce the shared universe.
